【症状7: CAM_Init / pipe start OK だが黒画面】
  LCD は buffer[1]=黒を表示し、frame IRQ で buffer 切替。IRQ 無しだと永久黒。
  また CMW が exposure/gain=min 固定 → AE 未動作時は真っ暗。
  対策:
    - Display_init 後に緑テストパターン（LCD 経路確認）
    - pipe start 後に LTDC を capture buffer[0] へバインド
    - 中間 exposure/gain
    - cam_mon: frames / csi_irq / dcmipp_irq を毎秒表示

【症状9: frames=0, csi_irq 大量, dcmipp_irq=0, ec=0xc8100】
  0xc8100 = CSI SYNC + DPHY_CTRL + LP_SYNC + SOT → D-PHY ロック失敗。
  landmarks: PLL1=800MHz → CSI=PLL1/40=20MHz
  BSP2 FSBL: PLL1=1200MHz → 同じ /40 だと CSI=30MHz（不正）
  対策: MX_DCMIPP_ClockConfig で PLL1 実周波数から CSI≈20MHz になる divider を計算

【症状10: frames≈30fps だが色ノイズちらつき, ec=0x8010】
  CSI は通った。0x8010 = PIPE1_OVR + DPHY_CTRL（sticky 1回）。
  ログ: CSI clk PLL1=64000000 /3 → GetPLL1 が HSI(bypass) を返していた。
  PLL1 bypass のままだと HCLK/XSPI が遅く PIPE overrun → 壊れた画素=色ノイズ。
  また単一バッファ表示はティアリングでノイズに見える。
  対策:
    - hl_ensure_pll1(): bypass なら FSBL 同様 1200MHz に復元
    - CSI divider はレジスタ由来 PLL1（/60 → 20MHz）
    - frame event で ping-pong 二重バッファ復帰
    - cam_mon: demosaic ビット / 毎秒 ErrorCode クリア

【症状11: PLL1 restore 後に PSRAM OK で停止、LED 点滅なし】
  PLL1 bypass→1200MHz 復元は成功 (SysClk=600MHz)。
  原因1: HAL_RCC_ClockConfig → HAL_InitTick が μT-Kernel SysTick を上書き
         → tk_dly_tsk が戻らずハング
  原因2: 高速 HCLK 後の NOR OPI Init がハング（VIDEO_ONLY では不要）
  対策:
    - os_bsp: HAL_InitTick を override → カーネル動作中は SysTick を retune
    - hl_xspi: VIDEO_ONLY で NOR skip

【症状12: cam_mon 正常(~30fps, demosaic=1, ovr=0) だが LCD が砂嵐】
  パイプは通っている。PLL1 restore 後も PSRAM を pre-boost (HCLK≈64MHz) のまま使用。
  MX_XSPI_RAM_Init の Refresh が遅いクロック基準のまま → MMP 読み書きが壊れ砂嵐。
  対策: hl_xspi_reclock() で DeInit + Init + MMP + R/W test（XSPI1≈200MHz をログ）

【実機 OK（2026/8/11）】
  post-boost XSPI1=200000000 / PSRAM R/W OK / LCD カメラ映像 / ~30fps err=0
